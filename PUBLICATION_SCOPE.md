# Published subset

Included: the final detector dependency closure, acquisition source, reference deployment helpers, final numerical outcomes, statistics verification, recorded dependency versions, and upstream notices.

Excluded: figures and plotting code/dependencies; benchmark task contents and native data; all `local-data/`; raw model responses, packets and execution logs; evaluation archives; taxonomy source excerpts; VM disk images and third-party executables; local audit reports, Git status snapshots, personal planning documents, and historical experiment outputs.

Numerical outcome records retain the information required to recompute results. Unneeded execution paths and free-text model diagnostics are omitted. Experimental predictions, denominators and metrics are unchanged.

AppWorld protected data and derivatives have an encrypted redistribution requirement. They are not supplied as plaintext or gzip files in this repository. Obtain upstream data under its own terms before constructing a local replay archive. Gzip is not encryption.

Historical source module names are retained where imported by the final detector. They do not identify additional published experimental versions. Deployment reference code still needs environment-specific provisioning; it is not a validated one-command installer for fresh VMs.
